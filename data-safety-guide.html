Google Play Console — 데이터 안전(Data Safety) 양식 입력 가이드

패키지: com.wejigsaw · 최종 업데이트: 2026-07-22 · 이 페이지는 앱 등록자가 Play Console의 데이터 안전 양식을 채울 때 참고하는 내부 가이드입니다.

0. 사전 체크

  • 이 앱은 로컬(DataStore) 데이터 + Google AdMob(앱 오픈/배너)만 사용. 별도 분석/크래시 SDK 없음.
  • 개인정보처리방침 URL(등록 필수): https://wesoft80.github.io/jigsaw/
  • 대상 사용자(별도 설문): 13세 이상(일반)으로 설정 — 아동 대상 아님.

1. "필수 사용자 데이터 유형을 수집 또는 공유하나요?"

예(Yes) 선택.

2. 선언할 데이터 유형 (각각 추가)

아래 표의 항목을 "데이터 유형 추가"로 하나씩 등록하세요. 이 외 유형(이름/이메일/전화, 결제, 건강, 메시지, 연락처, 캘린더, 파일/문서, 웹 검색, 오디오 등)은 수집하지 않음으로 미선택.

3. 각 유형별 세부 질문 답변

  • 공유(전송) 여부: 광고 관련 4개 유형(기기 ID/앱 상호작용/진단/대략적 위치) = 예(Google/AdMob과 공유). 사진·게임 진행도 = 아니오.
  • 임시 처리(ephemeral): 모두 아니오 — 데이터가 저장되거나 전송됨(임시 처리 아님).
  • 목적: 위 표의 "목적" 참고(광고·분석 / 앱 기능).
  • 사진·게임 진행도는 기기에만 저장되므로 "공유 아니오", "앱 기능" 목적.

4. 전송 중 암호화

예(Yes) — AdMob 통신은 HTTPS로 암호화됨.

5. 사용자 데이터 삭제 요청

예(Yes) — 로컬 데이터는 앱 삭제(또는 앱 데이터 삭제)로 즉시 삭제됨; 광고 데이터는 Google 개인정보/광고 설정을 통해 관리 가능. (설명 란에 동일 내용 입력)

6. 개인정보처리방침 URL

https://wesoft80.github.io/jigsaw/ 입력. (Pages repo는 public 유지 — private 전환 시 URL 접근 불가로 반려.)

7. 권한

INTERNET, ACCESS_NETWORK_STATE, VIBRATE — 일반 권한으로 별도 선언 양식 불필요. 사진은 시스템 사진 선택기 사용 → 저장공간/카메라 권한 미요청.

8. 제출 전 필수 (앱 단위)

  • AdMob 테스트 ID → 실제 앱 ID/광고단위 ID 교체(manifest, AppOpenAdManager, BannerAd). 테스트 ID 그대로 제출 시 광고 미노출 + AdMob 정책상 문제.
  • 스테이지 이미지 저작권/라이선스 확인(풍경·애완동물 등).
  • 릴리스 서명(keystore) + AAB 빌드.

주의: 데이터 안전 양식은 개인정보처리방침(한국어)의 "데이터 안전(요약)" 표와 반드시 일치해야 반려를 피할 수 있습니다.
